> Useful scripts and tools, mainly for installation across different platforms.

### macOS Setup

```sh
/bin/bash -c "$(curl -k https://raw.githubusercontent.com/Rodrigue2g/dotfiles/main/macos/setup.sh)"
```

### gtkmm Installation

```sh
/bin/bash -c "$(curl -k https://raw.githubusercontent.com/Rodrigue2g/dotfiles/main/scripts/gtk-install.sh)"
```

### Layout

```text
bash/       bash configuration
zsh/        zsh configuration
scripts/    runnable setup scripts
git/        git utilities
macos/      macOS setup and settings
embedded/   embedded development setup notes
homebrew/   Homebrew files and formulae
docs/       short installation notes
shared/     reusable public resources
webauthn/   WebAuthn test page and assets
```
